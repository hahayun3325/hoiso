# v98 expanded-family selection toolkit

This toolkit performs only a read-only residual morphology screen at the frozen nonlinear path sample. It does not run MANO, collect new derivatives, change bounds, create a pose, or launch an optimizer.

The 2D translation/rotation/scale fits are screening diagnostics. A route suggestion must still be reviewed by the professor and followed by source-seam, zero-identity, finite-difference stability, novelty, and bounded-capacity gates.
