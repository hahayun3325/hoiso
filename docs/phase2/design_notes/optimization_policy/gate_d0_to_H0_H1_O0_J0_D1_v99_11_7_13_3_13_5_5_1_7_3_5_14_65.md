# Gate D0 to H0/H1/O0/J0/D1 staged optimization

Generated: 2026-08-16T00:46:13.526739+00:00

Gate D0 emits semantic contact hypotheses, not transforms or optimizer weights.
The compiler resolves named fingers and object regions to hash-owned geometry.
The adapter then freezes all parameters and opens only the current phase's
allowlist.

1. H0 moves the complete hand through global rotation and translation while
   hand scale, MANO shape/articulation, Gate-A, and camera remain fixed.
2. H1 starts from an accepted H0 checkpoint and refines only reviewed
   contacting-finger MANO joints.
3. O0 refines the object while the accepted hand remains frozen.
4. J0 opens only the separately reviewed union of hand/object parameters.
5. D1 is a post-optimization jury for contact locality, visibility/z-order,
   penetration/collision, observation agreement, provenance, and regression.

H0 and H1 use separate configs, optimizer membership, checkpoints, and
rollback conditions. A zero-update live replay is an execution-integrity check,
not a claim that the initializer is already scientifically correct.
