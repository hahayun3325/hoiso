# Gate-B/D0 prompt-owner coordination and semantic-objective contract

This version preserves the professor toolkit question ontology while adopting the category-independent single-crop query boundary. Gate B and D0 are queried independently. Their answers are compiled only after both are frozen; neither model sees repository metadata or the other gate answer.

MoGe, Hunyuan image-to-shape, and HaMeR are image policies rather than text-prompt slots. The grounding stage uses a short positive project policy. D0 selects semantic adapters and trainable groups; it never chooses numerical weights, transforms, or metric depth. The live adapter, zero-update integrity capture, and all GPU phases remain unauthorized.
