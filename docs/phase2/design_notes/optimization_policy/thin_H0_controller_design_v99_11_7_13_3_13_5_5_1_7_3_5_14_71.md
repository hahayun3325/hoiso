# Thin D0-aware H0 controller

The controller delegates numerical optimization to an injected production-engine adapter. It owns only H0 policy: validated config loading, global rotation/translation allowlisting, frozen object/scale/articulation, one cached dense object raster, finite-gradient isolation, checkpoint/rollback, and zero-update capture.

H0 moves the whole articulated hand rigidly. H1 is a later, separate phase that may change only selected finger articulation. The canonical `run.py`, historical object-only scripts, and historical zero-step scripts remain unchanged.
